# Vocabulaire familier du dictionnaire de base

Le dictionnaire de 36Board vient de Lexique 3.83 et des sous-titres de films
(OpenSubtitles). Il connaît bien la langue écrite, beaucoup moins celle des messages :
`mdr` y apparaissait à peine, `ptdr` ou `tkt` pas du tout, et des mots aussi installés
que `feedback` ou `spoiler` étaient trop rares pour être jamais proposés.

Ce fichier ajoute ce vocabulaire, pour écrire sur un ton décontracté sans que le
clavier « corrige » ce qu'on tape exprès.

## Comment le lire

- **Fréquence** : le poids du mot dans les propositions. Repères dans le dictionnaire :
  la moitié des mots est sous 24, `bonjour` est à 49 118, `merci` à 148 144. Les valeurs
  ci-dessous restent modestes, pour qu'un mot familier ne passe jamais devant un mot
  courant qui commence pareil.
- **Un mot déjà présent garde la plus forte des deux fréquences** : la fusion relève les
  mots trop rares, elle n'en abaisse aucun.
- **Contrepartie assumée** : un mot ajouté n'est plus corrigé. Taper `pk` ne devient plus
  `ok`, puisque `pk` (pourquoi) est désormais un mot connu.

## Registres

| Registre | Où on le rencontre |
|---|---|
| **familier** | Conversation détendue, messages entre proches |
| **jeune** | Surtout chez les adolescents et les jeunes adultes |
| **réseaux sociaux** | Publications, commentaires, messageries de groupe |
| **courant** | Entré dans la langue de tous les jours, sans connotation particulière |
| **professionnel** | Jargon de bureau, réunions, mails de travail |

## Modifier cette liste

1. Ajouter, retirer ou corriger une ligne dans les tableaux ci-dessus.
2. Lancer `python dictionnaire/fusionner.py` : le script vérifie que le dictionnaire est
   trié, refuse les doublons, puis fusionne et réécrit `app/src/main/assets/fr_dict.txt`.
3. Lancer les tests (`./gradlew testDebugUnitTest`) : `DictionnaireFamilierTest` vérifie
   que chaque mot de ce fichier est bien dans le dictionnaire et que le tri tient toujours.

Retirer une ligne d'ici ne retire pas le mot du dictionnaire : la fusion ne fait
qu'ajouter ou relever.
